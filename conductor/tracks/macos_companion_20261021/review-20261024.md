## Findings and fixes

- **Fixed:** arithmetic accepted durations that could overflow when converted
  from seconds to milliseconds or added to a start timestamp. The parser now
  rejects either overflow, with a synthetic regression in the Swift test source
  and direct harness.
- **Fixed:** the initial Track 16 sequence test needed to remove Track 16's own
  scoped deferral when asserting that Track 15's deferral alone cannot unlock
  stage 5. The fault test now tests both boundaries: Track 16's explicit scope
  allows only bounded stage-5 work, and stage 6 remains blocked.
- **No further local findings:** the importer has no calendar side effects,
  rejects malformed/duplicate identities and unknown versions, and bounds input
  bytes and record count. Its schema remains prototype-only because no Android
  exporter compatibility is established.
